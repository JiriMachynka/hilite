The `hilite` package is built from four smaller ones. Most projects never import them directly, but each is usable on its own.

## @hilite/highlight

Names in, markup out. It wraps the loader from `@hilite/core` and the renderer from `@hilite/render`, over maps you pass in.

<Raw
  html={dl([

    ],
    [
      'codeToHtml(code, { lang, theme | themes, ...options })',
      'HTML string, byte for byte what Shiki writes. Options are those of `renderHtml`, including `transformers`.',
    ],
    ['codeToRendered(code, options)', 'Returns `{ html, css? }`, for `classMode`.'],
    ['codeToAnsi(code, { lang, theme })', 'Truecolor terminal output.'],
    ['codeToTokens(code, lang)', 'Raw tokens for every line.'],
  ])}
/>

```typescript title="highlighter.ts"
import { createHighlighter } from '@hilite/highlight'
import aliases from './dist/aliases.js'
import deps from './dist/deps.js'
import langs from './dist/langs/index.js'
import themes from './dist/themes/index.js'

const hilite = createHighlighter({ langs, deps, aliases, themes })
const html = await hilite.codeToHtml(code, { lang: 'ts', theme: 'github-dark' })
```

### Writing a transformer

A transformer is `{ tokens?, line?, pre? }`. `tokens(lines)` edits the token lists before markup, `line(line, number)` runs on each line and may change its classes, `pre(attrs)` edits the attributes of the outer element.

```typescript title="custom.ts"
const numbered: Transformer = {
  line: (line, n) => {
    line.classes.push(n % 2 ? 'odd' : 'even')
  },
  pre: (attrs) => {
    attrs['data-lang'] = 'ts'
  },
}
```

## @hilite/compiler

Build time only. Reads `tm-grammars` and the Shiki theme files and writes one module per language and per theme, a dependency map, aliases and a size and conversion report.

### Command line

<Raw
  html={dl([
    ['--out <dir>', 'Where to write. Default is the repo `dist`.'],
    ['--langs a,b,c', 'Write only these languages.'],
    ['--dict', 'Also measure a shared brotli dictionary and put the result in the report.'],
  ])}
/>

```shellscript
bun packages/compiler/src/cli-build.ts --langs typescript,python,css --out ./my-dist
```

### Functions

```typescript title="build.ts"
import { buildLanguages, buildThemes } from '@hilite/compiler'

const { reports } = await buildLanguages({ out: './dist', languages: ['typescript', 'css'] })
const themes = await buildThemes({ out: './dist' })
```

### Your own theme

```typescript title="theme.ts"
import { compileTheme } from '@hilite/compiler'
import { createTheme } from '@hilite/render'

// Any VS Code or Shiki theme object.
const theme = createTheme(compileTheme(myTheme))
```
