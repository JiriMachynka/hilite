Transformers edit the lines before they become markup. The comment markers are the same ones Shiki's `@shikijs/transformers` reads, and the output matches it ({int(transformers.notation.ok)} of {int(transformers.notation.all)} cases). Edit any example below and the output follows: add, move or delete a marker.

## Diff

`// [!code ++]` and `// [!code --]` add `diff add` and `diff remove` and remove the comment.

`focus` adds `focused`. The other lines blur until you hover the block.

## Use them

```typescript title="transformers.ts"
import { notationDiff, notationFocus, notationHighlight } from '@hilite/render'

await codeToHtml(code, {
  lang: 'ts',
  theme: 'github-dark',
  transformers: [notationDiff(), notationHighlight(), notationFocus()],
})
```

The transformers only add classes. Style them yourself:

```css title="transformers.css"
.line.diff.add { background: rgb(46 160 67 / 0.18); }
.line.diff.remove { background: rgb(248 81 73 / 0.18); }
.line.highlighted { background: rgb(110 118 129 / 0.25); }
pre.has-focused .line:not(.focused) { filter: blur(0.095rem); opacity: 0.6; }
```

Not ported: word highlight (`[!code word:x]`), error and warning levels, `{1,3}` meta strings and JSX-style markers.

## Write your own

A transformer is an object with up to three hooks. `tokens` edits the token lists, `line` runs on each line, `pre` edits the attributes of the outer element.

```typescript title="custom.ts"
const numbered: Transformer = {
  line: (line, n) => {
    line.classes.push(n % 2 ? 'odd' : 'even')
  },
  pre: (attrs) => {
    attrs['data-lang'] = 'ts'
  },
}
```
